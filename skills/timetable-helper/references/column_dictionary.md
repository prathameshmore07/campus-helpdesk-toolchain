# CSV Column Dictionary
- `batch`: Student section code (e.g., `CSE-A`, `CSE-B`).
- `day`: Full English weekday name (`Monday` through `Friday`).
- `time_slot`: 24-hour `HH:MM-HH:MM` interval.
- `course_code`: University course identifier (`L` suffix denotes lab).
- `course_name`: Official title of the course.
- `faculty`: Assigned instructor name.
- `room`: Lecture hall (`LH-*`) or laboratory (`LAB-*`).
- `type`: `Lecture` or `Lab`.
